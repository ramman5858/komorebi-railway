# こもれび鉄道

乗客を届けて資金を稼ぎ、列車と街を育てるブラウザゲームの試作です。

## 公開版

https://ramman5858.github.io/komorebi-railway/

PC・スマホ・iPadのブラウザから遊べます。進行状況は端末・ブラウザごとに保存され、ほかの端末とは同期しません。

## 遊び方

`node server.cjs` で起動し、 http://localhost:4173 を開きます。`index.html` をブラウザで直接開いても遊べます。

- マップまたは「押している間走る」ボタンを押し続けると前進し、指やマウスを離すとすぐ停止します。PCではボタンにフォーカスしてスペースまたはEnterを押し続けても走れます。
- 乗客を届けると運賃を獲得できます。
- 押し続けている間は駅を通過します。駅の近く（区間の端から8%以内）で指を離すと駅に停車し、乗客が乗り降りします。駅以外で止まっても乗客は乗り降りしません。別の駅に停車して乗客を届けたときだけ運賃を獲得します。
- 資金で速度・定員を強化し、最大5駅を開放できます。
- 資金・強化・駅・輸送人数はこのブラウザに保存します。列車の位置は再読込時に最初の駅に戻ります。
- バックグラウンドでは運行を止めます。放置中の収益はありません。

## iPadについて

Safariで公開版のURLを開いて遊べます。タッチ操作と画面幅に合わせた表示に対応しています。iPad実機では未検証です。

ホーム画面へのアプリ追加を想定した専用設定・オフライン対応は未実装です。フォントの取得には通信を使いますが、取得できなくても標準フォントで遊べます。
